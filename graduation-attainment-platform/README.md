# 面向专业认证的毕业要求达成度统一计算平台

本目录用于承载课程项目后续的前后端开发、数据库交付物、部署配置和应用级设计文档。

## 技术栈约定

- 前端：Vue 3 + Element Plus
- 后端：Spring Boot 3 + MyBatis-Plus
- 数据库：MySQL

## 目录说明

- `frontend/`：前端工程目录，后续由前端同学初始化和维护。
- `backend/`：后端工程目录，后续由后端同学初始化和维护。
- `sql/`：ER 图、DDL、初始化脚本、数据字典等数据库交付物目录。
- `deploy/`：Docker Compose、Nginx、环境变量模板、部署说明等部署目录。
- `docs/`：应用本身的设计文档目录，例如接口约定、模块说明、联调记录。

## 协作约定

- `frontend/` 与 `backend/` 下的实际工程文件由对应组员后续补充。
- 仓库根目录 `docs/` 继续存放课程协作与项目管理文档；本目录下的 `docs/` 只存放应用设计与开发文档。
