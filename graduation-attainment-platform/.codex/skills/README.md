# 项目内 skills 规划说明

本目录用于统一维护 `graduation-attainment-platform/` 的 repo-local AI skills。

约定如下：

- 每个 skill 使用独立目录，目录名即 skill 名称。
- 每个 skill 目录至少包含 `SKILL.md`；如需额外 agent 配置，可放在 `agents/` 子目录下。

当前已落地 skill：

- `action-api-design`：用于统一当前仓库的前后端接口命名、路径对齐与 `/api` 代理排查规范。

后续如果某一类任务频繁出现，按需在本目录下继续创建对应 skill 目录和内容文件。
