# 教师端课程教学班与成绩录入上下文接口测试

> 对应角色：课程主讲教师  
> 基础路径：`/api/teacherContext`  
> 请求方式：全部 `POST`  
> 请求头：`Content-Type: application/json`，`Authorization: Bearer <token>`

## 1. 查询当前教师课程与教学班

- Method: `POST`
- URL: `/api/teacherContext/listMyTeachingClasses`

请求体可为空，也可传筛选条件：

```json
{
  "courseId": 1,
  "termId": 1,
  "gradeYear": 2024,
  "classCode": "TC2024",
  "calcStatus": "unsubmitted"
}
```

期望响应 `data` 至少包含：

```json
[
  {
    "majorId": 1,
    "majorName": "计算机科学与技术",
    "gradeYear": 2024,
    "courseId": 1,
    "courseCode": "CS101",
    "courseName": "程序设计基础",
    "classId": 1,
    "classCode": "TC2024CS01",
    "className": "程序设计基础1班",
    "termId": 1,
    "termCode": "2025-2026-1",
    "calcStatus": "unsubmitted",
    "programMatched": true,
    "blockReason": null
  }
]
```

验收点：

- 只能返回当前教师负责的课程和教学班。
- 当课程与当前教师所属专业 + 教学班年级不匹配时，`programMatched=false`，`blockReason` 返回阻断说明。

## 2. 查询教学班学生名单

- Method: `POST`
- URL: `/api/teacherContext/listMyClassStudents`

```json
{
  "classId": 1
}
```

期望响应：

```json
[
  {
    "scId": 1,
    "studentId": 1,
    "studentNo": "20240101001",
    "studentName": "张三",
    "majorId": 1,
    "majorName": "计算机科学与技术",
    "enrollmentYear": 2024,
    "status": 1
  }
]
```

验收点：

- 只能查询当前教师负责的教学班。
- 传入其他教师负责的 `classId` 时，应返回 `403` 业务错误。

## 3. 查询成绩录入上下文

- Method: `POST`
- URL: `/api/teacherContext/getScoreImportContext`

```json
{
  "classId": 1
}
```

期望响应 `data` 至少包含：

```json
{
  "permission": {
    "userId": 1,
    "teacherId": 1,
    "teacherName": "李老师",
    "hasInstructorRole": true,
    "ownsTeachingClass": true,
    "canOperate": true,
    "blockReason": null
  },
  "teachingClass": {
    "majorId": 1,
    "majorName": "计算机科学与技术",
    "gradeYear": 2024,
    "courseId": 1,
    "courseCode": "CS101",
    "courseName": "程序设计基础",
    "classId": 1,
    "classCode": "TC2024CS01",
    "termId": 1,
    "termCode": "2025-2026-1",
    "calcStatus": "unsubmitted",
    "programMatched": true,
    "blockReason": null
  },
  "studentCount": 35,
  "courseObjectiveCount": 4,
  "assessmentPointCount": 8,
  "calcStatus": "unsubmitted",
  "canGenerateTemplate": true,
  "canImportScore": true,
  "blockReasons": []
}
```

验收点：

- 返回当前教学班学生总数。
- 返回当前课程目标数量。
- 返回当前考核点数量。
- 返回当前课程级计算状态。
- 返回是否允许生成模板、是否允许导入成绩。
- 当前教学班所属课程与当前教师专业 + 年级培养方案不匹配时，`canGenerateTemplate=false`、`canImportScore=false`，并在 `blockReasons` 中返回阻断信息。

## 4. 权限失败测试

### 4.1 无课程主讲教师角色

- Method: `POST`
- URL: `/api/teacherContext/listMyTeachingClasses`

```json
{}
```

期望：

```json
{
  "code": 403,
  "message": "当前账号不是课程主讲教师，无法访问教师端上下文接口",
  "data": null
}
```

### 4.2 未绑定教师身份

使用有 `instructor` 角色但没有 `teacher.user_id` 绑定的账号请求。

期望：

```json
{
  "code": 403,
  "message": "当前登录用户未绑定启用状态的教师身份",
  "data": null
}
```

## 5. 验收清单

- [ ] 教师端上下文接口可正常调用。
- [ ] 只返回当前教师负责的课程和教学班。
- [ ] 可正确返回 `majorId`、`majorName`、`gradeYear`、`courseId`、`courseCode`、`courseName`、`classId`、`classCode`、`termId`、`termCode`、`calcStatus`。
- [ ] 能查询教学班学生名单。
- [ ] 能返回成绩录入上下文。
- [ ] 能区分专业 + 年级培养方案上下文是否匹配。
- [ ] Swagger 文档可读。
