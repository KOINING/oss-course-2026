# 课程-毕业要求指标点支撑矩阵自测样例

> 所有接口均为 `POST /api/supportMatrix/*`，需携带 `Authorization: Bearer <token>`。  
> 推荐使用专业负责人账号进行联调。

## 1) 查询当前专业矩阵

```bash
curl -X POST "http://localhost:8080/api/supportMatrix/getSupportMatrix" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d "{\"majorId\":1,\"termId\":1}"
```

期望：返回 `data` 数组，元素包含 `courseId`、`ipId`、`weight`。

## 2) 批量保存矩阵（成功样例）

```bash
curl -X POST "http://localhost:8080/api/supportMatrix/saveSupportMatrix" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d "{
    \"majorId\": 1,
    \"termId\": 1,
    \"rows\": [
      {\"courseId\": 1, \"ipId\": 1, \"weight\": 0.40},
      {\"courseId\": 2, \"ipId\": 1, \"weight\": 0.60},
      {\"courseId\": 1, \"ipId\": 2, \"weight\": 0.30},
      {\"courseId\": 2, \"ipId\": 2, \"weight\": 0.70}
    ]
  }"
```

期望：`code=200`，`message=支撑矩阵保存成功`。

## 3) 批量保存矩阵（未配平失败样例）

下面示例中 `ipId=1` 的权重和为 `0.80`：

```bash
curl -X POST "http://localhost:8080/api/supportMatrix/saveSupportMatrix" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d "{
    \"majorId\": 1,
    \"rows\": [
      {\"courseId\": 1, \"ipId\": 1, \"totalWeight\": 0.30},
      {\"courseId\": 2, \"ipId\": 1, \"totalWeight\": 0.50}
    ]
  }"
```

期望：`code=400`，并包含类似提示：

```json
{
  "code": 400,
  "message": "指标点 IP01-1 校验失败：当前权重和=0.80，要求为1.00",
  "data": null
}
```

## 4) 单条新增/修改/删除支撑关系

### 4.1 新增

```bash
curl -X POST "http://localhost:8080/api/supportMatrix/addCourseIndicatorSupport" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d "{\"courseId\":1,\"ipId\":1,\"totalWeight\":0.40}"
```

### 4.2 更新

```bash
curl -X POST "http://localhost:8080/api/supportMatrix/updateCourseIndicatorSupport" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d "{\"cisId\":10,\"courseId\":1,\"ipId\":1,\"totalWeight\":0.45}"
```

### 4.3 删除

```bash
curl -X POST "http://localhost:8080/api/supportMatrix/deleteCourseIndicatorSupport" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d "{\"cisId\":10}"
```

> 单条保存也会执行当前指标点配平校验；若未配平将返回 `code=400` 和明确原因。
