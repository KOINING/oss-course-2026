# 达成度逐层追溯接口测试

## 前置条件

- 已登录并在请求头携带 `Authorization: Bearer <token>`。
- 当前账号角色为 `program_director` 或 `academic_affairs`。
- 数据库中已有专业、年级、支撑矩阵、课程目标、考核点、原始成绩，并已执行课程级/专业级计算。

## 1. 专业级 Gk 穿透到课程级 Ek

- Method: `POST`
- URL: `/api/achievementTrace/getMajorToCourseTrace`
- Body:

```json
{
  "majorId": 1,
  "gradeYear": 2022,
  "termId": 1,
  "ipId": 1
}
```

说明：`termId`、`ipId` 可不传。不传 `ipId` 时返回该专业年级下所有指标点的课程贡献来源。

## 2. 课程级 Ek 穿透到课程目标

- Method: `POST`
- URL: `/api/achievementTrace/getCourseToObjectiveTrace`
- Body:

```json
{
  "classId": 1,
  "ipId": 1
}
```

返回内容会说明该教学班该指标点的 `Ek` 来自哪些课程目标、每个课程目标达成度以及内部权重 `w`。

## 3. 课程目标穿透到考核点和原始成绩

- Method: `POST`
- URL: `/api/achievementTrace/getObjectiveToScoreTrace`
- Body:

```json
{
  "classId": 1,
  "coId": 1,
  "apId": 1
}
```

说明：`apId` 可不传。不传时返回该课程目标下全部考核点及对应学生原始成绩。

## 4. 导出逐层追溯台账

- Method: `POST`
- URL: `/api/achievementTrace/exportAchievementLedger`
- Body:

```json
{
  "majorId": 1,
  "gradeYear": 2022,
  "termId": 1,
  "ipId": 1
}
```

Apifox 中将响应保存为文件，文件类型为 `xlsx`。导出内容覆盖：专业、年级、学期、毕业要求、指标点、`Gk`、课程、教学班、`Ek`、宏观权重 `W`、课程目标、课程目标达成度、内部权重 `w`、考核点、满分、学生和原始成绩。

## 常见结果

- `403 当前账号无权访问达成度追溯接口`：登录账号角色不是专业负责人或教务管理员。
- `404 未查询到可追溯数据`：专业、年级、学期、指标点参数不匹配，或尚未配置支撑关系/成绩/计算结果。
- `404 教学班不存在`、`404 指标点不存在`、`404 课程目标不存在或不属于当前教学班课程`：下钻参数不是当前数据链路中的有效 ID。
