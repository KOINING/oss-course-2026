# 毕业要求与指标点联调自测样例

> 请求前请先登录专业负责人账号，替换示例中的 `<token>`。所有接口均为 `POST`，基础路径为 `/api`。

## 1. 新增毕业要求

```bash
curl -X POST "http://localhost:8080/api/requirements/addGraduationRequirement" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d "{\"grCode\":\"GR01\",\"grDescription\":\"能够应用工程知识解决复杂工程问题\",\"majorId\":1,\"status\":1}"
```

期望响应：

```json
{
  "code": 200,
  "message": "毕业要求创建成功",
  "data": null
}
```

## 2. 查询毕业要求

```bash
curl -X POST "http://localhost:8080/api/requirements/listGraduationRequirements" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d "{\"grCode\":\"GR01\",\"majorId\":1,\"status\":1}"
```

期望响应中的 `data` 至少包含：

```json
[
  {
    "grId": 1,
    "grCode": "GR01",
    "grDescription": "能够应用工程知识解决复杂工程问题",
    "majorId": 1,
    "majorName": "计算机科学与技术",
    "status": 1
  }
]
```

## 3. 新增指标点

```bash
curl -X POST "http://localhost:8080/api/requirements/addIndicatorPoint" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d "{\"ipCode\":\"IP01-1\",\"ipDescription\":\"能够运用数学与自然科学原理分析工程问题\",\"grId\":1,\"status\":1}"
```

## 4. 查询指标点

```bash
curl -X POST "http://localhost:8080/api/requirements/listIndicatorPoints" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d "{\"ipCode\":\"IP01\",\"grId\":1,\"status\":1}"
```

期望响应中的 `data` 至少包含：

```json
[
  {
    "ipId": 1,
    "ipCode": "IP01-1",
    "ipDescription": "能够运用数学与自然科学原理分析工程问题",
    "grId": 1,
    "grCode": "GR01",
    "grDescription": "能够应用工程知识解决复杂工程问题",
    "status": 1
  }
]
```

## 5. 停用与启用

```bash
curl -X POST "http://localhost:8080/api/requirements/updateGraduationRequirementStatus" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d "{\"grId\":1,\"status\":0}"

curl -X POST "http://localhost:8080/api/requirements/updateIndicatorPointStatus" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d "{\"ipId\":1,\"status\":0}"
```

期望响应分别为 `"毕业要求已停用"`、`"指标点已停用"`；将 `status` 改为 `1` 可恢复启用。

## 6. 删除

```bash
curl -X POST "http://localhost:8080/api/requirements/deleteIndicatorPoint" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d "{\"ipId\":1}"

curl -X POST "http://localhost:8080/api/requirements/deleteGraduationRequirement" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d "{\"grId\":1}"
```

若毕业要求下仍有关联指标点，期望返回：

```json
{
  "code": 400,
  "message": "该毕业要求下存在 N 个指标点，请先删除指标点后再删除毕业要求",
  "data": null
}
```
