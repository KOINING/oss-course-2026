# 第四周整改 - 第二阶段教师端闭环说明

## 阶段目标

完成教师端“课程配置 -> 模板生成 -> 成绩导入预校验 -> 保存成绩 -> 课程级计算 -> 锁定”的主链路。

## 本阶段已完成内容

### 1. 模板生成前置校验补齐

- 教师端成绩上下文新增内部权重 `w` 计数。
- 只有在满足以下条件时才允许生成模板和导入成绩：
  - 教学班已有学生名单
  - 课程已配置课程目标
  - 课程已配置考核点
  - 课程已配置内部权重 `w`
  - 当前教学班未锁定

### 2. 成绩导入改为真实预校验链

- 前端上传文件后不再直接“导入成功”，而是先走 `/api/teacher/importScorePreview`。
- 后端实际解析 `.xlsx / .xls / .csv`，校验：
  - 固定列是否为“学号、姓名”
  - 模板中的考核点列是否与当前课程配置一致
  - 满分行是否与考核点满分一致
  - 课程目标行是否与当前配置一致
  - 学号是否属于当前教学班
  - 姓名是否与当前教学班学生名单一致
  - 成绩是否为空、是否为数字、是否超出满分
  - 文件内是否存在重复学号

### 3. 成绩保存链打通

- 预校验通过后，前端会将后端返回的可保存成绩明细提交到 `/api/teacher/saveScores`。
- 保存成功后，教学班状态更新为 `score_imported`。

### 4. 课程级计算与锁定打通

- 前端新增“计算并锁定”操作，调用 `/api/teacher/calcCourseAchievement`。
- 后端完成：
  - 学生-课程目标达成度 `Cij`
  - 班级课程目标平均达成度 `C̄j`
  - 课程级指标点达成度 `Ek`
- 课程级计算完成后：
  - `course_indicator_achievement.is_locked = true`
  - `teaching_class.calc_status = locked`

### 5. 教师端页面收口

- 模板预览页增加：
  - 前置条件阻断提示
  - 模板下载
  - 重新预览
- 成绩导入页增加：
  - 预校验结果展示
  - 保存成绩
  - 课程级计算并锁定
  - 锁定后的只读提示
  - 课程级计算结果回显
