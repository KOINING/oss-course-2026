# 第二周测试文档

## 1. 文档目的

本文档用于支撑第二周阶段性验收，覆盖当前网站中已经落地的前端功能测试。

测试范围仅包含以下已实现模块：

- 登录
- 首页
- 账号与角色管理
- 基础数据模块
- 毕业要求与指标点模块

本文档不包含尚未完成真实业务闭环的占位页面模块，如支撑矩阵、课程目标、成绩录入与报表导出。

---

## 2. 测试目标

第二周测试目标如下：

- 验证当前前端页面已接入真实后端接口
- 验证第二周要求的基础 CRUD 功能可正常使用
- 验证不同角色访问菜单与页面权限符合预期
- 验证关键操作的异常提示、表单校验和页面交互完整
- 为第二周联调记录、验收结论和录屏材料提供执行依据
