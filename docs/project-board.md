# Project 看板使用说明

本项目使用 GitHub Project 管理任务进度。

## 看板状态说明

- `Todo`：任务已创建，等待开始
- `In Progress`：负责人正在处理
- `Review`：已提交 Pull Request，等待审核
- `Done`：Pull Request 已合并，任务完成

## 使用规则

每个 Issue 创建后应加入 Project，并设置负责人 Assignee。

任务开始时，将 Issue 移动到 `In Progress`。

创建 Pull Request 后，将 Issue 移动到 `Review`。

Pull Request 合并后，将 Issue 移动到 `Done`。
