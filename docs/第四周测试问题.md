课程主讲老师端——课程目标与考核点：

- 课程目标配置页签：课程目标列表项的操作列增加功能——进入权重配置、进入考核点配置，操作列的输出的二次确认弹窗的按钮要水平排列（左取消，右确认删除）
- 课程目标与考核点中菜单项对应页面的所有页签中的“根据《软件需求规格说明书》B-2，教师端只展示当前课程在当前专业、年级版本下负责支撑的指标点，并配置课程目标对这些指标点的内部贡献权重。”这种解释文字的宽度要一行显示，显示不下才换行，而不是像现在这样固定宽度
- 三个页签进入时默认都要显示一个课程/教学班的数据，而不是现在这样进入就要选择课程和教学班的空白页
- 考核点配置页签中考核点数据的状态列评估一下还需要吗

课程主讲老师端——成绩录入与计算：

- 成绩模板预览页签：页签名改为“成绩预览”；页面内的表格整体高度增加，以便显示更多学生成绩数据
- 两个页签进入时默认都要显示一个课程/教学班的数据，而不是现在这样进入就要选择课程和教学班的空白页
- 教师保存成绩后怎么看不到，成绩模板预览界面中表格区不是应该展示学生成绩吗，同时支持简单的数据查缺补漏操作。
- 成绩录入页签中保存成绩后，成绩应显示在成绩预览区；计算并锁定入口是否应该放在成绩预览区域在学生成绩都有数据时由教师操作，而不是在成绩导入区；
- 在教师确认原始成绩无误后点击计算。
  - 系统按引擎规则，依次计算本课程的“目标级达成度”**以及**“课程级毕业要求指标点达成度”。
  - 计算完成后，系统将上述两级结果持久化至数据库，并将该课程的成绩单状态变更为“已锁定”。
