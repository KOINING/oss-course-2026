# 第四周整改第一阶段：接口与入口对齐说明

## 1. 阶段目标

第一阶段只处理两类问题：

- 模块 B / C 的页面入口是否唯一、是否清晰
- 前端 API 封装与后端现有 Controller 路径是否一致

本阶段不处理：

- 成绩导入真实预校验
- 课程级计算公式正确性
- 专业级汇总闭环

## 2. 入口收口结果

### 模块 B

- 统一保留 `/course-objectives` 作为模块 B 唯一入口
- 将原本分散的“课程目标配置”和“内部权重配置”收口到同一入口页签：
  - `课程目标配置`
  - `内部权重配置`

### 模块 C

- 继续保留 `/assessment` 作为模块 C 唯一入口
- 阶段一仅调整其下子页面的接口映射，不重构页面结构
