# 前端接口文档 - 基础数据模块

> 本文档由前端1（王子嘉）提供，供后端1同学实现接口时参考

## 接口概述

基础数据模块包含两个子模块：
- 学年学期管理
- 学院管理

所有接口均采用 **POST** 请求，请求体和响应体均为 **JSON** 格式。

---

## 一、学年学期管理接口

### 1.1 查询学年学期列表

**接口地址：** `POST /api/basic/academicTerm/list`

**请求参数：**

```json
{
  "termName": "2023-2024",  // 可选，学年学期名称（模糊查询）
  "pageNum": 1,              // 可选，页码，默认1
  "pageSize": 10             // 可选，每页条数，默认10
}
```

**响应示例：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 25,
    "list": [
      {
        "id": 1,
        "termName": "2023-2024学年第一学期",
        "startDate": "2023-09-01",
        "endDate": "2024-01-15",
        "createTime": "2023-08-01 10:00:00",
        "updateTime": "2023-08-01 10:00:00"
      }
    ]
  }
}
```

**字段说明：**
- `id`: 学年学期ID
- `termName`: 学年学期名称
- `startDate`: 开始日期（格式：YYYY-MM-DD）
- `endDate`: 结束日期（格式：YYYY-MM-DD）
- `createTime`: 创建时间
- `updateTime`: 更新时间

---

### 1.2 新增学年学期

**接口地址：** `POST /api/basic/academicTerm/add`

**请求参数：**

```json
{
  "termName": "2024-2025学年第一学期",
  "startDate": "2024-09-01",
  "endDate": "2025-01-15"
}
```

**响应示例：**

```json
{
  "code": 200,
  "message": "新增成功",
  "data": {
    "id": 26
  }
}
```

**校验规则：**
- `termName`: 必填，长度1-50字符
- `startDate`: 必填，日期格式
- `endDate`: 必填，日期格式，且必须晚于 `startDate`

---

### 1.3 编辑学年学期

**接口地址：** `POST /api/basic/academicTerm/update`

**请求参数：**

```json
{
  "id": 26,
  "termName": "2024-2025学年第一学期（修改）",
  "startDate": "2024-09-01",
  "endDate": "2025-01-20"
}
```

**响应示例：**

```json
{
  "code": 200,
  "message": "更新成功",
  "data": null
}
```

**校验规则：**
- `id`: 必填
- 其他字段同新增接口

---

### 1.4 删除学年学期

**接口地址：** `POST /api/basic/academicTerm/delete`

**请求参数：**

```json
{
  "id": 26
}
```

**响应示例：**

```json
{
  "code": 200,
  "message": "删除成功",
  "data": null
}
```

**注意事项：**
- 如果该学年学期已被其他数据引用，应返回错误提示，不允许删除

## 三、统一响应格式

所有接口均遵循以下响应格式：

```json
{
  "code": 200,        // 状态码：200成功，其他为失败
  "message": "操作成功", // 提示信息
  "data": {}          // 响应数据，可为对象、数组或null
}
```

**常见错误码：**
- `200`: 成功
- `400`: 请求参数错误
- `401`: 未登录或token过期
- `403`: 无权限
- `500`: 服务器内部错误

## 五、数据库表结构建议

### 5.1 学年学期表（academic_term）

```sql
CREATE TABLE academic_term (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  term_name VARCHAR(50) NOT NULL COMMENT '学年学期名称',
  start_date DATE NOT NULL COMMENT '开始日期',
  end_date DATE NOT NULL COMMENT '结束日期',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_term_name (term_name)
) COMMENT='学年学期表';
```

### 5.2 学院表（college）

```sql
CREATE TABLE college (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  college_name VARCHAR(50) NOT NULL COMMENT '学院名称',
  college_code VARCHAR(20) COMMENT '学院代码',
  description VARCHAR(200) COMMENT '学院描述',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_college_name (college_name)
) COMMENT='学院表';
```

## 七、注意事项

1. 所有接口必须进行**登录鉴权**，未登录用户应返回401
2. 所有接口必须进行**权限校验**，无权限用户应返回403
3. 所有接口必须进行**参数校验**，参数错误应返回400并给出明确提示
4. 删除操作建议做**关联检查**，避免数据不一致
5. 日期格式统一为 `YYYY-MM-DD`
6. 时间格式统一为 `YYYY-MM-DD HH:mm:ss`
