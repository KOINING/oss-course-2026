# 第一周任务分配

这周的定位是：**协作磨合周 + 基础工程周**。  
本周不追求做很多业务功能，重点是把架构、ER、协作流程、前后端骨架、部署环境先跑顺。

**路线：Java 敏捷企业级生态（国内高校教务系统主流）**

- **后端支撑：** 采用 **Java (JDK 21)** 配合 **Spring Boot 3** 框架构建微服务或单体架构。利用 MyBatis-Plus 或 Spring Data JPA 处理复杂的双层权重矩阵校验与持久化。
- **数据流处理：** 采用 Alibaba EasyExcel 或 Apache POI，应对百人级、多考核点复合表头模板的高效生成与内存安全解析。
- **前端展示：** **Vue 3** 配合 Element Plus ，构建数据响应迅速的后台 SPA，通过标准 RESTful 接口与后端交互。

##### **通用数据存储层（跨技术栈要求）：**

- **关系型数据库：** 必须选用强事务支持的关系型数据库，选择 **MySQL 8.0+**。
- **底层优化要求：** 因计算链路涉及“考核点 → 目标 → 指标点”的多表深度联表查询，需针对 `CourseID`、`ObjectiveID` 和 `IndicatorID` 建立联合索引，并严格配置事务隔离级别（如 Read Committed 或 Repeatable Read）以支持“成绩锁定”的并发安全机制。
