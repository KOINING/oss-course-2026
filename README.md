# oss-course-2026

开源软件通识课程小组协作项目。

## 项目简介

本仓库用于开源软件通识课程的小组协作开发实践。小组成员将通过 GitHub 完成项目文档编写、任务分配、分支开发、Pull Request 提交、代码 Review 和版本发布等开源协作流程。

本项目旨在帮助小组成员熟悉开源软件开发的基本流程，包括：

- 使用 GitHub 管理项目代码和文档
- 使用 Issue 进行任务分配与进度跟踪
- 使用分支进行独立开发
- 使用 Pull Request 进行代码合并申请
- 使用 Code Review 提高项目质量
- 使用 Markdown 编写项目文档
